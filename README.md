# macOS USB Creator

macOS Versions it creates: OS X 10.9 Mavericks to macOS 26 Tahoe.

Minimum OS you can use this tool with: OS X 10.9 Mavericks.

# Instructions to open the program
Step 1: Download from the releases (latest is highly recommended).

Step 2: Open "Terminal" and type in "cd Downloads" (or cd wherever you saved it).

Step 3: Type in "chmod +x macos_usb_creator-v1.2.sh" or "chmod +x whatever you saved the file as" (you only need to do this step on first opening).

Step 4: Type in "./macos_usb_creator-v1.2.sh" or "./whatever you saved the file as".
