# macOS USB Creator
A macOS program that allows to create macOS USBs.

Versions it creates: OS X 10.11 El Capitan to macOS 26 Tahoe

Minimum OS: OS X 10.9 Mavericks

# Instructions to open the program
Step 1: Download from the releases (latest is highly recommended).

Step 2: Open "Terminal" and type in "cd Downloads" (or cd wherever you saved it).

Step 3: Type in "chmod +x macos_usb_creator-v1.0.sh" or "chmod +x whatever you saved the file as" (you only need to do this step on first opening).

Step 4: Type in "./macos_usb_creator-v1.0.sh" or "./whatever you saved the file as".
